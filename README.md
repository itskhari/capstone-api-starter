A Spring Boot REST API that supports porducts, categories, shopping carts, profiles, and orders for a simple online store.

Features
- View Products and Categories
- Search Filter (Min/Max Price, Category, and Subcategory

Admin Tools
- Abilty to create, update, or delete products or categories.

User Features
- Manage shopping cart
- View and update your profile
- Place Orders

Security
- Admins manage products and categories
- Users manage carts, profiles, and orders
- Guest are able to browse inventory

Architecture
- Controller -> Service -> Repository -> Database
